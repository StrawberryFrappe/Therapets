# Internacionalización (i18n)
{: .no_toc }

1. TOC
{:toc}

La app soporta **Español (es)** e **Inglés (en)** con detección automática del
idioma del dispositivo y cambio manual.

## Configuración

`l10n.yaml` en la raíz:

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
synthetic-package: false
```

- Cadenas fuente en `lib/l10n/*.arb` (`app_en.arb`, `app_es.arb`).
- `pubspec.yaml` tiene `generate: true`; las clases
  `app_localizations*.dart` se **generan**.

## Añadir o cambiar una cadena

1. Añade la clave en `lib/l10n/app_en.arb` (plantilla) y su traducción en
   `app_es.arb`.
2. Regenera: `flutter gen-l10n` (o `flutter pub get` / `flutter run`, que lo
   disparan).
3. Úsala en el código: `AppLocalizations.of(context)!.tuClave`.

```json
// app_en.arb
{ "feedButton": "Feed", "@feedButton": {"description": "Botón para alimentar"} }
// app_es.arb
{ "feedButton": "Alimentar" }
```

## LocaleService

`lib/services/locale_service.dart` (inyectado como `ChangeNotifierProvider`):

- Detecta el idioma del dispositivo al iniciar.
- Permite override manual (botones de bandera en Ajustes), persistido en
  SharedPreferences.
- Notifica a `TherapetsApp` para reconstruir con el nuevo `locale`.

> Mantén la **paridad** entre `app_en.arb` y `app_es.arb`: una clave que falte en
> un idioma cae al idioma plantilla.
{: .warning }
