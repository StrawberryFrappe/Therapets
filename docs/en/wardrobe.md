# Wardrobe
{: .no_toc }

1. TOC
{:toc}

Clothing customizes Bob, and some items grant a **passive happiness bonus**.
It is bought with **gold**, which you earn by completing [daily missions](daily_missions.html).

![Wardrobe]({{ '/assets/images/screenshots/04_wardrobe.png' | relative_url }})
*The wardrobe: buy items with gold and equip them on Bob's head.*

> Bob is a "ball" (*ball*), so he only has a **head** slot: all items are
> hats/head accessories.
{: .note }

## Clothing catalog

|------|:------------:|:---------------:|
| 🎩 Elegant Hat | 50 | — |
| 🍂 Leaf Beret | 100 | +5% |
| 🌸 Flower Crown | 120 | +10% |
| 🧣 Winter Earmuffs | 150 | +5% |
| 🕶️ Sunglasses | 200 | +5% |

## Buying and equipping

1. Open the **wardrobe** from the main screen.
2. Buy an item (gold is deducted). It becomes **unlocked**.
3. Select an unlocked item to **equip** it.
4. Equipping a new item to the head **replaces** the previous one.

The happiness bonus of the equipped item is applied passively.
