# Internationalization (i18n)
{: .no_toc }

1. TOC
{:toc}

The app supports **Spanish (es)** and **English (en)** with automatic device-language
detection and manual switching.

## Configuration

`l10n.yaml` at the project root:

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
synthetic-package: false
```

- Source strings in `lib/l10n/*.arb` (`app_en.arb`, `app_es.arb`).
- `pubspec.yaml` has `generate: true`; the `app_localizations*.dart` classes are
  **generated**.

## Adding or changing a string

1. Add the key to `lib/l10n/app_en.arb` (template) and its translation to
   `app_es.arb`.
2. Regenerate: `flutter gen-l10n` (or `flutter pub get` / `flutter run`, which
   trigger it automatically).
3. Use it in code: `AppLocalizations.of(context)!.yourKey`.

```json
// app_en.arb
{ "feedButton": "Feed", "@feedButton": {"description": "Button to feed the pet"} }
// app_es.arb
{ "feedButton": "Alimentar" }
```

## LocaleService

`lib/services/locale_service.dart` (injected as `ChangeNotifierProvider`):

- Detects the device language at startup.
- Allows manual override (flag buttons in Settings), persisted in
  SharedPreferences.
- Notifies `TherapetsApp` to rebuild with the new `locale`.

> Maintain **parity** between `app_en.arb` and `app_es.arb`: a key missing in
> one language falls back to the template language.
{: .warning }
