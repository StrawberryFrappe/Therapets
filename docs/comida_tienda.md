# Comida y Tienda
{: .no_toc }

1. TOC
{:toc}

La comida sube el **hambre** (y a veces la **felicidad**). Se compra con **plata**,
que ganas jugando [minijuegos](minijuegos.html).

![Tienda de comida]({{ '/assets/images/screenshots/02_store.png' | relative_url }})
*La tienda de comida con los cinco alimentos y su precio en plata.*

## Catálogo de comida

| Comida | Precio (plata) | + Hambre | + Felicidad |
|--------|:-------------:|:--------:|:-----------:|
| 💧 Agua | 5 | +5 % | — |
| 🍎 Manzana | 10 | +10 % | +5 % |
| 🍰 Pastel | 40 | +15 % | +25 % |
| 🍔 Hamburguesa | 50 | +40 % | +10 % |
| 🍣 Sushi | 80 | +20 % | +30 % |

> La hamburguesa es la más eficiente para el **hambre**; el sushi y el pastel dan
> más **felicidad**. Los valores se suman y se limitan al 100 %.
{: .tip }

## Comprar y alimentar

1. Abre la **tienda de comida** desde la pantalla principal.
2. Compra la comida deseada (se descuenta la plata).
3. La comida se guarda en el **refrigerador** (inventario).
4. Abre el refrigerador y selecciona un alimento para dárselo a Bob.

Alimentar también cuenta para la misión diaria **"Yummy Time"** (ver
[Misiones diarias](misiones_diarias.html)).

## Refrigerador (inventario)

El refrigerador guarda las cantidades de cada comida que has comprado. Cada vez
que alimentas a Bob, se descuenta una unidad. Si una comida llega a 0, desaparece
del inventario.
