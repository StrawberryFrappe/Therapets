# Guardarropa
{: .no_toc }

1. TOC
{:toc}

La ropa personaliza a Bob y algunas prendas dan un **bonus pasivo de felicidad**.
Se compra con **oro**, que ganas completando [misiones diarias](misiones_diarias.html).

> Bob es una "bola" (*ball*), así que solo tiene la ranura de **cabeza**: todas las
> prendas son sombreros/accesorios de cabeza.
{: .note }

![Guardarropa]({{ '/assets/images/screenshots/04_wardrobe.png' | relative_url }})
*El guardarropa: compra prendas con oro y equípalas en la cabeza de Bob.*

## Catálogo de ropa

| Prenda | Precio (oro) | Bonus felicidad |
|--------|:-----------:|:---------------:|
| 🎩 Sombrero Elegante | 50 | — |
| 🍂 Boina de Hojas | 100 | +5 % |
| 🌸 Corona de Flores | 120 | +10 % |
| 🧣 Orejeras de Invierno | 150 | +5 % |
| 🕶️ Lentes de Sol | 200 | +5 % |

## Comprar y equipar

1. Abre el **guardarropa** desde la pantalla principal.
2. Compra una prenda (se descuenta el oro). Queda **desbloqueada**.
3. Selecciona una prenda desbloqueada para **equiparla**.
4. Equipar una prenda nueva en la cabeza **reemplaza** la anterior.

El bonus de felicidad de la prenda equipada se aplica de forma pasiva.
